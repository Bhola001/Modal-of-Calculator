# Calculator App

A simple and responsive Calculator Web App built using HTML, CSS, and JavaScript. This project performs basic arithmetic operations with a clean and user-friendly interface.

## Features

* Addition (+)

* Subtraction (-)

* Multiplication (*)

* Division (/)

* Clear All button

* Input validation

* Responsive design

* Easy-to-use interface

## Technologies Used

* HTML5

* CSS3

* JavaScript

## How to Use

1. Enter the first number.

2. Enter the second number.

3. Select an operation.

4. Click the **Calculate** button.

5. View the result instantly.

6. Click **Clear All** to reset the calculator.
